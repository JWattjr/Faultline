# Reviewer demo (under 60 seconds)

This walkthrough is ready for a public deployment. The current Vercel deployment is protected by team SSO, and no Studio Next contract or proof has been published yet; do not present local fixture previews as live chain results.

1. Open the live page. Point out the Studio Next chain, deployed contract, selected charter, attempt, and `DEMO accounting` label.
2. Switch among **Accepted**, **Remediation**, and **Breached** from the case selector.
3. Open the trace for one agent and follow its output hash into the next handoff's previous-output hash. Open the fixture; note the synthetic-fixture and charter/attempt labels.
4. Show the clause inspector and consensus result. Call out the distinct transaction lifecycle, GenVM execution result, validator/finality details, and explorer link.
5. Open the receipt. Explain that the model supplies only a normalized outcome and clause/role fields; contract code computes rewards, refunds, and bond effects from the sealed charter.
6. On **Remediation**, point out that no role is assigned and no accounting moves while attempt 2 is opened. On **Breached**, show Research `PRIMARY`, Analysis `CONTRIBUTING`, and Delivery `CLEAR`.

The public review does not require a wallet. A wallet is needed only to submit transactions.
